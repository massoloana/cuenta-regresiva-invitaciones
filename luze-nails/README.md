# Luze Nails

Web para el estudio de uñas de Candela: promoción de servicios.

## Estructura

- `referencias-esteticas/` — inspiración visual: webs, paletas, tipografías, capturas de Instagram/Pinterest.
- `servicios/imagenes/` — fotos de los trabajos y servicios de Candela.
- `servicios/videos/` — videos de los servicios.
